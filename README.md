# Midway / Taito 8080 (Space Invaders) hardware for MiSTer

One core for the MAME `mw8080bw.cpp` / `8080bw.cpp` / `rotaryf.cpp` sets, rewritten in SystemVerilog.
MRAs are generated from MAME by `tools/gen_mra.py`.
